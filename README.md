# Bare & Bloom

React + TypeScript + Vite + Tailwind CSS landing page for Bare & Bloom.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Main files

- `src/App.tsx` — page composition
- `src/components/` — reusable UI components
- `src/data/products.ts` — product/category data
- `src/lib/whatsapp.ts` — WhatsApp ordering helper
- `src/index.css` — Tailwind + global styles

## Visual direction

The UI uses a livelier fashion/footwear palette: warm cream, energetic coral, rich purple and small gold accents. The goal is to keep the beauty side premium without making the site feel like a skincare-only brand.
